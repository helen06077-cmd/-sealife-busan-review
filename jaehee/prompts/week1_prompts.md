# 1주차 VS Code AI 프롬프트 (B 역할)

## 프롬프트 ① 공통 규칙 — 새 대화를 열 때마다 맨 먼저 붙여넣기

```
너는 내 팀 프로젝트의 데이터 담당(B) 보조야. 아래 규칙을 이 대화 내내 지켜.

[프로젝트]
- 이름: GREEN ROUTE BUSAN — 부산 관광 수요예측 기반 저탄소 여행 경로 추천 서비스 (3인, 6주)
- 내 역할(B): 데이터 확보, 방문 수요 예측모델, 성능 검증
- 1주차 목표: 공식 방문 데이터 샘플 확보 → 데이터 인벤토리 작성 → 금요일까지 예측 단위(월별/일별)와 예측 대상(관광지 3~5곳 또는 일부 권역) 제안
- 데이터 소스: ① 관광지식정보시스템 주요관광지점 입장객 통계(월별, 실측 입장객) ② 한국관광 데이터랩 지역별 방문자수(이동통신 기반 추정치)

[저장 규칙 — 가장 중요]
- 작업 폴더는 bus-02 저장소 안의 jaehee/ 하나뿐이다. 새로 만들거나 고치는 파일은 전부 jaehee/ 아래에 저장해.
- jaehee/ 밖의 파일(hyebeen/, jiwon/, report/, inputs/, 루트 파일)은 읽기만 하고 절대 수정·삭제·이동하지 마.
- 폴더 구조:
  jaehee/
  ├─ data/raw/        내가 내려받은 원본 (절대 수정 금지, 파일명: 출처_내용_받은날짜)
  ├─ data/processed/  정리한 데이터
  ├─ scripts/         파이썬 스크립트
  ├─ notes/           조사 메모, 작업 로그(work-log.md)
  ├─ prompts/         프롬프트 모음
  └─ data_inventory.md
- 작업을 끝낼 때마다 jaehee/notes/work-log.md 맨 아래에 "날짜 · 한 일 · 만든/바꾼 파일 · 다음 할 일"을 한 줄씩 추가해.

[데이터 원칙]
- 실측 입장객 수와 이동통신 기반 추정치를 섞지 말고, 표와 메모에 '성격'을 항상 구분해서 적어.
- 관광지점 입장객을 '부산 전체 관광객 수'로 해석하지 마.
- '혼잡도'라는 말 대신 '방문 수요'라고 써.
- 숫자는 반드시 파일에서 계산해서 쓰고, 추측으로 채우지 마. 모르면 '확인 필요'라고 적어.

[git]
- 작업 브랜치는 jaehee-week1. main에 직접 커밋하지 마.
- 커밋은 jaehee/ 경로만 add 해 (git add jaehee/). 커밋 메시지는 한국어로 "[B] 무엇을 했는지".
- API 키·비밀번호는 jaehee/.env 에만 두고 커밋하지 마.

[대화 방식]
- 나는 AI 프로젝트가 처음이야. 명령어를 실행하기 전에 무엇을 하는지 한 줄로 설명하고, 결과는 쉬운 말로 요약해 줘.
- 파일을 지우거나 덮어쓰기 전에는 먼저 나에게 물어봐.

규칙을 이해했으면 "규칙 확인" 이라고만 답해.
```

## 프롬프트 ② 작업 폴더 준비 (할 일 3번) — 지금 실행

```
지금 할 일: jaehee/ 작업 폴더 준비.

1. git status 와 현재 브랜치를 확인하고, 내 변경사항이 없으면 git pull 해 줘.
2. jaehee-week1 브랜치를 만들고 그 브랜치로 바꿔 줘 (이미 있으면 그 브랜치로 이동만).
3. 공통 규칙의 폴더 구조대로 jaehee/ 아래 폴더를 만들고, 빈 폴더에는 .gitkeep 을 넣어 줘.
4. jaehee/data_inventory.md 를 아래 표 틀로 만들어 줘. 값은 모르니 전부 '확인 필요'로 둬.
   | 출처 | 공간 단위 | 시간 단위 | 기간 | 부산 대상 수 | 결측·휴업 | 이용 조건 | 성격(실측/추정) | 원본 파일 |
   행: 관광지식정보시스템 주요관광지점 입장객 / 한국관광 데이터랩 지역별 방문자수
5. jaehee/notes/work-log.md 를 만들고 오늘 한 일을 첫 줄로 적어 줘.
6. jaehee/.gitignore 를 만들어 .env 를 넣어 줘.
7. 만든 파일 목록을 보여 주고, git add jaehee/ 후 "[B] 1주차 작업 폴더 준비" 로 커밋해 줘. push 는 내가 확인한 뒤에 할게.
```

## 프롬프트 ③ 입장객 통계 파일 확인 (할 일 1번) — 사이트에서 파일을 받아 jaehee/data/raw/ 에 넣은 뒤 실행

```
지금 할 일: 관광지식정보시스템에서 내려받은 부산 주요관광지점 입장객 통계 파일 확인.

파일 위치: jaehee/data/raw/ (파일명: 여기에 적기)

1. 원본은 건드리지 말고, 먼저 파일의 시트 이름, 머리글(열 이름), 앞 10줄을 보여 줘. 구조가 애매하면 진행하기 전에 나에게 물어봐.
2. jaehee/scripts/inspect_tour_stats.py 를 만들어서 아래를 계산해 줘 (pandas 사용, 필요하면 설치 방법도 알려 줘).
   - 부산 관광지 수와 이름 목록
   - 관광지별 데이터 시작 연월 ~ 끝 연월, 전체 개월 수
   - 관광지별 결측 월(공란·0) 수와 해당 연월
   - 끊김 없이 3년(36개월) 이상 이어진 관광지 목록 → 예측 대상 후보
3. 결과를 jaehee/notes/tour_stats_check.md 에 표로 저장하고, 정리한 데이터는 jaehee/data/processed/busan_monthly_visitors.csv (열: place_name, year_month, visitors) 로 저장해 줘.
4. data_inventory.md 의 '관광지식정보시스템' 행에서 확인된 칸만 채워 줘. 확인 못 한 칸은 '확인 필요'로 남겨.
5. 끝으로 3줄 요약: "부산 관광지 N곳 / 기간 / 예측 대상 후보" 를 보여 주고, work-log.md 에 기록한 뒤 "[B] 입장객 통계 확인" 으로 커밋해 줘.
```
