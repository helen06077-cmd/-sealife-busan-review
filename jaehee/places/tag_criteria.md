# 장소 태그 기준표 (초안 v0.1 · 2026-11-17 · 작성 B)

- 대상: `places/region_candidates.csv` 의 장소(place_id 기준). A·B가 반씩 태깅한다.
- 상태: **초안**. 확인 출처 2종(아래)은 아직 내려받지 않았음 → 해당 칸은 '확인 필요'.
- 좌표·주소는 C와 ID 체계를 맞춘 뒤 채운다(이 표에서는 다루지 않음).

## 0. 공통 규칙 (점수가 사람마다 달라지지 않게)

1. **출처가 있으면 출처가 우선**, 없을 때만 아래 판단 기준으로 매긴다. 어떤 근거로 매겼는지 `근거` 칸에 `출처명` 또는 `기준` 으로 적는다.
2. **애매하면 낮은 점수**를 주고 메모에 이유를 적는다(예: 1점인지 2점인지 모르겠으면 1점).
3. 장소의 **대표 동선(처음 온 사람이 보통 걷는 코스)** 기준으로 판단한다. 일부 구역만 되면 그 사실을 메모에 적는다.
4. 계절·시간에 따라 달라지면(예: 해수욕장 여름 개장) **연중 평상시** 기준으로 매기고 메모에 적는다.
5. **보정 회차**: 태깅 시작 전에 A·B가 같은 5곳(권역별 1곳)을 각자 매겨서 비교하고, 점수가 다르게 나온 태그는 이 문서의 예시를 고친다.
6. '혼잡도'라는 표현은 쓰지 않는다(→ '방문 수요').

## 1. 방문단위 적합도 (각 0~2점)

| 태그 | 뜻 | 값 | 판단 기준 (2점 / 1점 / 0점) | 확인 출처 |
|---|---|---|---|---|
| `fit_solo` 혼자 | 혼자 와도 어색하지 않고 즐길 거리가 있는가 | 0/1/2 | **2**: 혼자 걷기·관람이 주 활동(산책로, 박물관, 사찰, 카페거리). 1인 입장·1인 메뉴 가능 · **1**: 혼자 가능하지만 주로 단체·커플 이용(테마파크, 2인 이상 메뉴 위주 식당가) · **0**: 2인 이상만 이용 가능하거나 혼자 할 활동이 거의 없음(2인 이상 예약제 체험 등) | 확인 필요(시설 이용 안내) |
| `fit_couple` 연인 | 둘이 데이트 장소로 고를 만한가 | 0/1/2 | **2**: 야경·노을 명소이거나 분위기 있는 공간이 핵심(해변 야경, 전망대, 카페거리) · **1**: 데이트로 가능하지만 핵심 목적은 아님(박물관, 시장) · **0**: 아이·학습·운동 중심 시설(어린이 체험관, 교통공원) | 기준 |
| `fit_friends` 친구 | 친구 2~4명이 함께 놀기 좋은가 | 0/1/2 | **2**: 함께 하는 활동이 있음(먹거리 탐방, 해변 놀이, 체험·액티비티) · **1**: 같이 가도 되지만 각자 관람 위주(박물관, 사찰) · **0**: 조용히 해야 하거나 아이 대상 시설 | 기준 |
| `fit_family` 가족 | 성인 가족(부모+성인 자녀 등)이 함께 가기 좋은가 | 0/1/2 | **2**: 세대 구분 없이 즐기고 쉴 곳이 있음(아쿠아리움, 공원, 해변 산책로) · **1**: 가능하지만 연령대 취향이 갈림(카페거리, 클럽·바가 많은 거리) · **0**: 특정 연령만 대상(어린이 전용 시설, 성인 전용) | 기준 |
| `fit_kids` 아이와 함께 | 미취학~초등 아이를 데리고 가기 좋은가 | 0/1/2 | **2**: 아이 대상 체험·전시가 있거나 아이 화장실·수유실이 있음(과학관, 아쿠아리움, 교통공원) · **1**: 아이 대상은 아니지만 위험하지 않고 놀 공간이 있음(넓은 공원, 모래사장) · **0**: 계단·절벽·인파 등으로 아이 동반이 위험하거나 어려움, 또는 연령 제한 | 확인 필요(시설 안내의 수유실·연령 제한) |
| `fit_senior` 어르신 동반 *(선택)* | 65세 이상 어르신과 무리 없이 다닐 수 있는가 | 0/1/2 | **2**: 경사·계단이 적고 쉬는 곳·화장실이 가까움 · **1**: 일부 오르막·계단이 있지만 대표 동선은 가능 · **0**: 긴 계단·급경사가 대표 동선(예: 마을 골목 계단길, 산길) | 한국관광공사 열린관광지 목록 — 확인 필요 |

## 2. 시설·접근 태그

| 태그 | 뜻 | 값 | 판단 기준 | 확인 출처 |
|---|---|---|---|---|
| `indoor` 실내 여부 | 비·더위·추위에도 대표 활동을 할 수 있는가 | `실내` / `혼합` / `실외` | **실내**: 대표 동선의 80% 이상이 지붕 아래(박물관, 아쿠아리움, 과학관) · **혼합**: 실내 시설과 실외 동선이 섞임(전망대+산책로, 온천+거리) · **실외**: 대표 동선이 거의 실외(해변, 마을, 산책로, 사찰) | 기준 (시설 안내도로 확인) |
| `stroller` 유모차 접근 | 유모차를 밀고 대표 동선을 다닐 수 있는가 | 0/1/2 | **2**: 계단 없이 대표 동선 전체 이동 가능(엘리베이터·경사로 있음), 또는 열린관광지 목록에 유아 동반 편의 표시 · **1**: 대표 동선 일부만 가능하거나 우회로가 있음 · **0**: 계단·모래·흙길이 대표 동선이라 유모차를 접거나 들어야 함 | 한국관광공사 열린관광지 목록 — 확인 필요 |
| `wheelchair` 휠체어 접근 | 휠체어로 대표 동선과 화장실을 이용할 수 있는가 | 0/1/2 | **2**: 열린관광지로 지정되었거나, 대표 동선 무단차 + 장애인 화장실 있음 · **1**: 일부 구역만 가능(예: 전망대만 가능, 산책로는 불가) · **0**: 대표 동선에 계단·급경사가 있어 이용 불가 | 한국관광공사 열린관광지 목록 — 확인 필요 |
| `stay_min` 평균 체류시간 | 보통 머무는 시간 | 정수(분), **30분 단위**로 반올림 (30/60/90/120/180…) | ① 공식 안내의 관람 소요시간이 있으면 그 값 → ② 없으면 대표 동선을 걷는 시간(지도 도보시간) + 관람시간 추정 → `근거`에 '추정' 표시. 식사 시간은 시장·먹거리 장소만 포함 | 확인 필요 (공식 소요시간 자료 미확보) |
| `region` 권역 | 5개 권역 중 어디인가 | 원도심·영도 / 서면·동래 / 수영·남구 / 해운대·기장 / 서부 낙동강 | `region_candidates.csv` 의 region 값을 그대로 쓴다. 군구 기준이며 예외(감천문화마을→원도심·영도)와 미정(북구)은 `notes/tour_stats_check.md` 참고 | 1차 확정 계획안 |
| `visitbusan_pass` 비짓부산패스 | 비짓부산패스로 무료·할인 이용이 가능한가 | `Y` / `N` / `확인 필요` (+ 외국인 전용이면 `Y(외국인 전용)`) | 공공데이터포털의 부산관광공사 비짓부산패스 관광지 데이터에 장소가 있으면 Y. 패스 자체가 외국인 대상이면 모든 Y에 `(외국인 전용)` 표시. 데이터에 없으면 N | 부산관광공사 비짓부산패스 관광지 데이터(공공데이터포털) — 확인 필요 (외국인 전용 여부 포함) |
| `transit_15min` 대중교통 도보 15분 이내 | 가장 가까운 도시철도역 또는 버스정류장에서 입구까지 걸어서 15분 이내인가 | `Y` / `N` | 지도 앱 **도보 경로 시간**으로 판단(직선거리 아님). 기준점은 장소 **주 출입구**(마을·해변은 대표 진입로·안내소). 버스는 **배차 30분 이내** 노선의 정류장만 인정. 15분 정확히는 Y | 기준 (지도 앱 확인, 확인 날짜를 메모에 적기) |
