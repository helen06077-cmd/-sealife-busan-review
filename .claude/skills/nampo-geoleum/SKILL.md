# 남포 걸음 목소리 (출처: `sunghan/brand/persona.md`, `sunghan/brand/worldview.md` · 2026-11-19)

- 목적: 누가 어떤 글을 부탁해도 남포 걸음의 말투와 사실로 쓴다. 이름은 '동래온천 하루 코스(가칭)'에서 바뀌었다. 동래온천 자산은 팀 자료에 없으므로 동래온천 이야기는 쓰지 않는다.
- **사실 규칙이 말투보다 먼저다.** 확인되지 않은 것을 확인된 것처럼 쓰지 않는다. 둘이 부딪치면 말투를 버린다.
- 듣는 손님: 서면에 묵고 60대 어머니를 모시고 원도심을 하루에 둘러보는 최민재(KTX로 오는 국내 여행자). persona.md 3절.
- 말투(1절 5번)·핵심 메시지(2절)·금칙어(3절)·예시 문장(5절)은 모두 사람이 정했다(결정 2026-11-19, sunghan). 이 파일에 [제안]은 남아 있지 않다.

## 1. 톤 (말투 규칙)
1. 숫자는 원문 그대로 쓰고 성격을 붙인다. 실측과 통신·카드 결합 추정치를 섞지 않는다. (worldview 5절 사실 2)
2. 거리는 '직선'을 붙여 말한다: "직선 593m". 실제 걷는 길이는 모른다. (결정 2026-11-19, worldview 5절)
3. 근거가 한 출처뿐인 사실은 "○○ 자료에 따르면"으로 쓴다. (worldview 쓰는 규칙)
4. 광고 글·근거 없는 최상급을 쓰지 않는다. 팀 자료에 근거 없는 사람과 장면을 넣지 않는다. (worldview 5절 사실 1·3)
5. **조용하고 다정한 존댓말로 쓴다.** (결정 2026-11-19, sunghan · worldview 5절 [각색] 후보에서 고름)

## 2. 핵심 메시지 셋 — 결정 2026-11-19, sunghan
1. "매일 같은 자리에서 문을 열고, 옆 시장까지 걸어서 데려다주는 사람" (persona 2절 한 줄 소개에서 고름)
2. "자료에 있는 것만 말하고, 차 없이 걸어갈 수 있는 길을 먼저 알려 드릴게요." (persona 2절 약속에서 고름)
3. "무리하지 않는 하루" — 많이 보는 것보다 다 함께 끝까지 걷는 것 (worldview 4절 [각색]에서 고름)

## 4. 사실로만 쓸 것 (값 · 출처)
**시장 값(여는 날·점포수·취급품목·화장실·직선거리)은 같은 폴더의 [markets.md](markets.md)를 먼저 읽는다.** 거기 없는 시장 값은 쓰지 않는다. 시장을 더할 때는 원문 행을 확인해 markets.md에 넣는다.

| 사실 | 값 | 출처 |
|---|---|---|
| 자갈치 방문객 중 60대 | 23.1% — **추정치** | 코레일 보고서(2021년 4~6월 통신·카드 결합 추정치)에 따르면 |
| 두 시장 축제 | 2026-09·2026-10에 이미 끝남, 다음 일정 자료 없음. 열리는 것처럼 쓰지 않는다 | worldview 1절·'쓰지 않을 것' |

**값이 엇갈리는 것 — 사람이 정하기 전까지는 둘 다 적고, 하나로 고르지 않는다**
- 남포동건어물도매시장 주소: **시장 표 「부산광역시 중구 용미길10번길 1(지번 중구 남포동1가 62-1)」(`busan_markets.csv` 155행)을 쓴다** (결정 2026-11-19, sunghan). 축제 표 「부산광역시 중구 용미길9번길6-45(지번 중구 남포동1가 79-2)」(`busan_festivals.csv` 24행)는 쓰지 않는다. 실제로 맞는지는 현장 확인 전
- 자갈치시장 좌표: 두 표의 주소는 같고 좌표만 위도 0.00002·경도 0.00001 안팎 다름 (worldview 1절)

**모르는 것 — "아직 확인 못 했어요"라고 쓴다**: 실제 걷는 길이·계단·오르막(현장 확인 #6·#7), 시간대 혼잡, 상인 한 사람의 모습·말, 세 시장의 손님 후기. 긴 근거는 worldview '채우지 못한 것' 표를 본다.
